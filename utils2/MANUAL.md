# VB5K Boundary Marker — 사용 설명서

## 개요

초음파 A-mode 신호(CSV)에서 **표피 시작(T0)**, **피하지방 시작**, **근막(Fascia)** 경계를 수동으로 마킹하고 JSON으로 저장하는 도구입니다.

---

## 실행

```bash
cd utils2
python3 boundary_marker_gui.py
```

## 기본 워크플로우

### 1단계: CSV 파일 열기
- **[Open CSV]** 버튼 클릭 → 캡처 파일 선택
- 파일 로드 완료 시 **T0(표피 시작)가 자동 검출**되어 주황색 선으로 표시됨
- 마커 모드가 자동으로 **피하지방시작** 모드로 전환

### 2단계: T0 확인
- 자동 검출된 T0가 올바른지 확인
- **잘못된 경우**: [Clear Markers] 한 번 클릭 → Start 모드로 복귀 → 클릭으로 수동 설정

### 3단계: 피하지방 시작 마킹 (빨간 점선)
- 그래프에서 **표피 에코가 끝나는 지점** 클릭
- 마커 모드가 자동으로 **Fascia** 모드로 전환

### 4단계: 근막(Fascia) 마킹 (파란 점선)
- 두 번째 에코 클러스터 시작 지점 클릭

### 5단계: 저장
- **[Save JSON]** 클릭 → **CSV 파일과 같은 폴더**에 `파일명_positions.json` 저장

## 마커 설명

| 마커 | 색상 | 의미 |
|------|------|------|
| Start (T0) | 주황색 실선 | 표피 시작점 (첫 에코 진입) |
| 피하지방시작 | 빨간 점선 | 표피 에코 종료 = 피하지방층 시작 |
| Fascia | 파란 점선 | 근막/두 번째 에코 시작 |

> **표피두께** = T0 ~ 피하지방시작
> **Gap** = 피하지방시작 ~ Fascia (진피+피하지방 합산)

## 네비게이션 버튼

| 버튼 | 기능 |
|------|------|
| ◀ Prev / ▶ Next | **같은 폴더** 내 이전/다음 파일로 이동 |
| ◀◀ 동부위 / 동부위 ▶▶ | **같은 부위 번호**(pos_num)의 다른 환자 파일로 이동 |

- 버튼에 `[현재/전체]` 형식으로 위치 표시 (예: `동부위 ▶▶ [3/20]`)
- 동부위 이동: **Data Root** 폴더 이하 전체에서 같은 `(번호)` 파일 검색
- Data Root 미설정 시: 현재 파일 위치에서 3단계 상위 폴더를 자동 사용

## 기타 기능

### Clear Markers
파일당 Clear Markers를 누를 때마다 마지막 마커부터 순차 삭제:
```
Fascia → 피하지방시작 → Start → (초기화)
```

### Compare (파형 비교)
- 이전 파일과 현재 파일을 겹쳐서 비교
- 비교 모드에서 **그래프 위를 드래그**하면 이전 파형을 좌우로 이동(정렬)
- **[⟳ Align]** 버튼으로 이동 초기화

### Envelope / Dark 토글
- **Envelope**: 힐버트 포락선 표시 ↔ 원시 ADC 신호 표시
- **Dark**: 다크/라이트 테마 전환

### Data Root (보라색 버튼)
동부위 네비게이션의 검색 범위가 되는 **최상위 데이터 폴더** 설정.
- 설정값은 `us_marker.config`에 저장되어 다음 실행 시에도 유지됨
- 예: `usdata/` 폴더를 선택하면 그 아래 모든 환자 폴더가 검색 대상
- Data Root 설정 후 동부위(◀◀/▶▶) 버튼이 활성화됨

### JSON 저장 위치
JSON 파일은 **항상 CSV 파일과 같은 폴더**에 저장됩니다.
- 예: `usdata/data/20260225/김선일/파일명_positions.json`
- 나중에 학습 데이터 수집 시 아래 예시처럼 스크립트로 한곳에 모을 수 있습니다:
```bash
# 환자별 JSON 수집 예시
find usdata/ -name "*_positions.json" | while read f; do
    cp "$f" labels/$(basename $(dirname $f))_$(basename $f)
done
```

## 파일 형식

### 입력: CSV
- utils3 캡처 형식: ADC 정수값(0~255), 1줄 1샘플, 헤더 없음
- 구형 오실로스코프 형식: `시간(s),전압(V)` — 자동 감지

### 출력: JSON
```json
{
  "source_file": "환자명_날짜_시간_(01)이마_M.csv",
  "start_point_us": 13.40,
  "positions": [
    { "position_name": "피하지방시작", "time_us": 14.82, "thickness_mm": 1.08 },
    { "position_name": "Fascia",       "time_us": 21.50, "thickness_mm": 6.25 }
  ]
}
```

---

## 파일명 규칙 (동부위 검색 필수)

```
이름_날짜_시간_(번호)부위명_성별.csv
예: 김선일_20260225_161114_(01)이마 중앙_M.csv
```

파일명이 이 규칙을 따르지 않으면 동부위(◀◀/▶▶) 버튼이 비활성화됩니다.
