# Ultrasound ADC Capture Tool (VB5K)

VB5K 장치에서 초음파 ADC 데이터를 캡처하고 저장하는 Windows GUI 프로그램입니다.

## 실행 방법

```bash
py -3 adc_capture_gui.py
```

## 화면 구성

```

│ Serial    Port:[COM3▼] [Refresh] Baud:[115200▼] [Connect] ● │

├─────────────────────────────────────────────────────────────┤

│ [Quick Save][Set Folder][Load CSV][Compare][Clear] □Envelope│
```

## 사용 순서

### 1. 연결
1. **Port** 드롭다운에서 COM 포트 선택 (마지막 사용 포트 자동 선택)
2. **Connect** 버튼 클릭
3. 녹색 ● 표시되면 연결 성공

### 2. 환자 정보 입력
- **Patient**: 환자 이름/ID 입력
- **Gender**: M 또는 F 선택
- **Position**: 마우스 휠로 측정 위치 변경, 우클릭으로 확정

### 3. 캡처
1. **Capture** 버튼 클릭
2. 프로그레스 바로 진행 상황 확인
3. "Done: xxxx samples" 메시지 확인
4. 그래프에 신호 표시됨

### 4. 저장
1. 처음 저장 시 **Set Folder** 버튼으로 저장 폴더 설정
2. **Quick Save** 버튼 클릭
3. 파일명 자동 생성: `환자명_날짜시간_위치_성별.csv`

## 버튼 설명

| 버튼 | 기능 |
|------|------|
| **Connect/Disconnect** | 시리얼 연결/해제 |
| **Refresh** | COM 포트 목록 새로고침 |
| **Capture** | ADC 데이터 캡처 시작 |
| **Quick Save** | 현재 데이터를 설정된 폴더에 자동 저장 |
| **Set Folder** | 저장 폴더 지정 |
| **Load CSV** | 기존 CSV 파일 불러오기 |
| **Compare** | 직전 캡처 데이터와 비교 (빨간색 오버레이) |
| **Clear** | 현재 그래프 지우기 |
| **Envelope** | Hilbert 변환 엔벨로프 표시 ON/OFF |
| **Dark** | 다크/라이트 테마 전환 |

## 측정 위치 설정

첫 실행 시 또는 **Edit** 버튼으로 측정 위치 목록 편집 가능
- 최소 4개, 최대 22개 위치
- 한 줄에 하나씩 입력

## 위치 선택 방법

| 동작 | 기능 |
|------|------|
| **마우스 휠** | 측정 위치 변경 (이전/다음) |
| **우클릭** | 위치 확정 (녹색 깜빡임) |

## 데이터 형식

저장되는 CSV 파일은 ADC 값만 한 줄에 하나씩 저장됩니다:
```
126
135
129
...
```

## 문제 해결

| 증상 | 해결 방법 |
|------|----------|
| 포트가 안 보임 | Refresh 버튼 클릭, USB 케이블 확인 |
| 연결 실패 | 다른 프로그램에서 포트 사용 중인지 확인 |
| 캡처 타임아웃 | VB5K 전원 확인, 케이블 연결 확인 |
| 그래프가 안 보임 | Clear 후 다시 캡처 |

## 설정 파일

프로그램 종료 후에도 설정이 유지됩니다:
- `usdata_config.json`: 측정 위치 목록
- `usdata_settings.json`: 마지막 사용 설정 (폴더, 환자, 포트 등)
